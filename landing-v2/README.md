# Sylica AI Landing Page

A scientifically-designed, interactive landing page for Sylica AI - the private interview copilot.

## Psychological Design Principles Applied

1. **Hick's Law** - Minimal navigation choices, clear singular CTAs
2. **Fitt's Law** - Large, easily accessible buttons in high-attention areas
3. **Von Restorff Effect** - Unique gradient text and floating elements that stand out
4. **Social Proof** - Testimonials, user counts, company logos prominently displayed
5. **Authority** - Technical credibility through feature depth and stats
6. **Scarcity/Urgency** - Limited-time trial messaging with clear value proposition
7. **Reciprocity** - Free trial offer without credit card requirement
8. **Progressive Disclosure** - Information revealed gradually through scroll
9. **Color Psychology** - 
   - Green (growth/success) for primary actions and trust signals
   - Blue (trust/technology) for accents and secondary elements
   - White space for clarity and reduced cognitive load
10. **Gestalt Principles** - Grouping of related features, continuity in layout

## Design Features

- **White/Light Theme** - Clean, professional, reduces eye strain
- **Interactive Elements** - Floating animations, hover effects, micro-interactions
- **Custom Illustrations** - Mock UI demonstrating the actual product
- **Scroll Animations** - Framer Motion powered fade-ins and transitions
- **Responsive Design** - Mobile-first approach with Tailwind CSS
- **Accessibility** - Focus visible states, reduced motion support

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

```bash
cd landing-v2
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.

## Build for Production

```bash
npm run build
```

The static export will be in the `dist` folder.
