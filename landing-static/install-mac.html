Install on macOS

Get Sylica AI running on your Mac in under a minute.

Pick the right download for your Mac, then complete a one-time first-launch step.

1. Choose your download

Not sure which one you have? Click the Apple menu in the top-left corner of your Mac, then About This Mac. If you see "Apple M1", "M2", "M3", or "M4", pick Apple Silicon. If you see "Intel", pick Intel.

  • Apple Silicon (M1 / M2 / M3 / M4) — Sylica-AI-arm64.dmg
  • Intel Macs — Sylica-AI-x64.dmg

2. Install the app

  1. Double-click the downloaded .dmg file.
  2. Drag the Sylica AI icon onto the Applications folder shortcut in the window that opens.
  3. Eject the DMG from your Desktop or Finder sidebar when the copy finishes.

3. First launch — one-time security approval

Because this build is not yet signed with an Apple Developer ID, macOS Gatekeeper requires a one-time approval the first time you open Sylica AI.

If you double-click Sylica AI and see a dialog saying "Apple cannot check it for malicious software":

  1. Close the dialog.
  2. Open Applications in Finder.
  3. Right-click (or Control-click) the Sylica AI icon.
  4. Choose Open from the menu.
  5. In the new dialog that appears, click Open again.

That's it. From the second launch onward you can double-click normally — macOS remembers your approval.

If macOS 15 (Sequoia) doesn't show an Open button, the dialog only offers Done. In that case:

  1. Click Done to dismiss it.
  2. Open System Settings → Privacy & Security.
  3. Scroll to the Security section near the bottom.
  4. Click Open Anyway next to the Sylica AI notice.

Troubleshooting

  • "App is damaged and can't be opened" — this is the Gatekeeper quarantine flag. Open the Terminal app and run xattr -cr /Applications/Sylica\ AI.app, then try again.
  • App opens but quits immediately — make sure you downloaded the right architecture for your Mac (Apple Silicon vs Intel above).
  • Microphone, screen recording, or accessibility prompts — grant them when asked. Sylica AI needs screen recording to see what you see, microphone for voice mode, and accessibility for global shortcuts. You can manage these any time in System Settings → Privacy & Security.
