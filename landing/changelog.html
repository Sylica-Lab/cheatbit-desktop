Release notes

Recent product changes across the desktop app, installer, updater, and site.

This changelog focuses on the latest public builds and website improvements. It is meant for users who want to see what changed before updating.

March 10, 2026 · v1.0.28

Upgrade installs no longer show uninstall offboarding

  • Fixed the Windows installer flow so upgrade installs do not trigger the uninstall retention prompt.
  • Published a fresh versioned installer, blockmap, and update metadata to the self-hosted update feed.
March 10, 2026 · v1.0.27

Uninstall offboarding dialog sizing fix

  • Expanded the desktop window before showing uninstall offboarding so users no longer need to scroll through a cramped modal.
  • Kept the standard widget size for the main app after the dialog closes.
March 10, 2026 · v1.0.26

Uninstall offboarding launched from inside the app

  • Added a Windows uninstall retention flow that opens Sylica AI before final removal.
  • Included plan-management and continue-uninstall actions inside the app UI.
March 10, 2026 · v1.0.25

Self-hosted Windows updates

  • Replaced the old GitHub-token updater path with a Cloudflare-hosted generic update feed.
  • Added the inline Update and Restart button inside the main widget.

Need the latest build?

Use the current website installer for a fresh install, or use the in-app updater on v1.0.25 and later.
